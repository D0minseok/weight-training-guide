# 웨이트 트레이닝 입문 가이드 (Weight Start)

웨이트 트레이닝을 처음 접하는 사람을 위한 **부위별 운동 가이드** 웹사이트입니다.
가슴 · 등 · 어깨 · 팔 · 하체 다섯 부위로 나눠, 각 운동의 자세 · 초보자 팁 · 흔한 실수 · 추천 세트를 정리했습니다.

## 기능

- **5개 부위** 분류: 가슴 / 등 / 어깨 / 팔 / 하체 (총 30여 개 운동)
- **사이드바 내비게이션**: 부위를 펼쳐 운동을 바로 선택
- **검색**: 운동 이름, 영어명, 장비(덤벨·바벨·머신 등), 자극 부위(광배근·햄스트링 등)로 즉시 검색
- **운동 상세 페이지**: 동작 방법(단계별), 초보자 팁, 흔한 실수, 추천 세트·반복, 이전/다음 운동 이동
- **입문자 공통 가이드**: 세트·반복·휴식, 점진적 과부하, 준비운동, 부상 신호
- 운동 사진을 배경으로 사용해 동기 부여 (이미지 출처: [Unsplash](https://unsplash.com))
- 반응형 (모바일에서는 사이드바가 슬라이드 메뉴로 전환)

## 실행 방법

빌드 도구가 필요 없는 정적 사이트입니다.

- 가장 간단: `index.html`을 브라우저로 열기
- 로컬 서버 (권장 — 일부 브라우저의 파일 제한 회피):
  ```bash
  # Python 3
  python -m http.server 5173
  # 그 후 http://localhost:5173 접속
  ```

## 폴더 구조

```
weight-training-guide/
├── index.html            # 레이아웃 (사이드바 + 본문)
├── assets/
│   ├── css/style.css     # 전체 스타일 (다크 테마, 반응형)
│   └── js/
│       ├── data.js       # 운동 데이터베이스 (부위, 운동, 가이드)
│       └── app.js        # 해시 라우팅, 렌더링, 검색, 사이드바
└── README.md
```

## 운동을 추가·수정하려면

`assets/js/data.js`의 `EXERCISES` 배열에 항목을 추가하면 사이드바·검색·상세 페이지에 자동 반영됩니다.

```js
{
  id: "고유-id",
  category: "chest",          // chest | back | shoulder | arm | leg
  name: "운동 이름",
  english: "English Name",
  level: "초급",               // 초급 | 중급 | 고급
  equipment: "덤벨",           // 맨몸 | 덤벨 | 바벨 | 머신 | 케이블
  primary: ["대흉근"],
  secondary: ["삼두근"],
  image: "https://images.unsplash.com/photo-...?auto=format&fit=crop&w=1200&q=80",
  steps: ["1단계", "2단계", "3단계"],
  tips: ["팁1", "팁2"],
  mistakes: ["실수1", "실수2"],
  sets: "3세트 × 8~12회, 세트 간 휴식 90초",
}
```

## 주의

이 사이트의 내용은 일반적으로 널리 알려진 운동 정보를 정리한 것으로, 개인별 맞춤 처방이 아닙니다.
통증·부상·기저질환이 있다면 운동 전 트레이너나 의료진과 상담하세요.
